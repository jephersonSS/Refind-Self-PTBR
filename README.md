## 📖 Sobre o projeto

Tradução gratuita e não oficial de **Refind Self: The Personality Test Game** para português brasileiro, desenvolvida a partir de uma tradução comunitária, revisada com auxílio de inteligência artificial e testada diretamente no jogo.

O projeto conta com mais de 1.200 correções linguísticas e contextuais, buscando oferecer uma localização natural, intuitiva e fiel à experiência original.

## 📋 Informações

- **Versão da tradução:** Final 1.3
- **Versão compatível do jogo:** 1.1.0502
- **Cobertura estimada:** 99–100%
- **Plataforma:** Windows 64 bits
- **Idioma:** Português brasileiro (PT-BR)

## ✨ Recursos

- Menus, diálogos e tutoriais traduzidos.
- Descrições das personalidades e resultados em português.
- Revisão gramatical e contextual.
- Instalador com detecção automática da Steam.
- Backup e restauração dos arquivos originais.
- Preservação dos saves e configurações.
- Instalação offline.

## 🛠️ Tecnologias utilizadas

- Go
- UnityFS
- IL2CPP
- Patches binários
- SHA-256
- API nativa do Windows
